# Plyr Native Replacer
A userscript that replaces native HTML5 video players with the [Plyr](https://github.com/sampotts/plyr) player.

## Installation:
1. Open `plyr-native-replacer.user.js`
2. Copy the code into your userscript manager of choice, eg. [Tapermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://github.com/violentmonkey/violentmonkey)
